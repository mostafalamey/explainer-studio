# Cut-Paper Diorama

Use `style: "cut-paper-diorama"` with the shared project contract.

Build a layered cardstock shadowbox. Shapes have slightly irregular scissor-cut outlines, visible fibres, pale exposed rims, contact shadows and depth-dependent cast shadows. Use cream stock, navy lettering, teal and soft cyan scenery, warm yellow foundations and coral focal objects. Preserve the real brand logo.

Use embedded Archivo Black at weight 400. Headlines should be at least 44 logical pixels, key numbers 60 or larger, and supporting labels around 28. Treat words as cut letters with optional pale backing; avoid excessive labels over the scene.

Create props from separate `paperize` layers with `compose`, `cutLines` and faceted circles. Cache textures and sprites. Set `window.PAPER_SCALE = context.canvas.width / 1280` before drawing; sprite helpers retain logical dimensions while painting native-resolution textures. The optional style CSS in the catalog embeds the font offline.

Stage one continuous physical world. Slide paper layers with subtle parallax, drop labels with a small settling bounce, reveal cut-strip arrows, and use hinged or lifted motion. Cast shadows respond to elevation. Use tactile clicks, restrained paper rustles and a quiet call chime beneath narration.

Keep content and existing narration identical across comparison examples. Sample the ticket reveal, call and final reception pose. Check readable digits, paper texture, crisp native-resolution edges, overlapping tags and clipped shadows. Export and verify the actual video before adding its shot and narrated preview to the style selector.

The supplied reference is preserved in `assets/styles/cut-paper-diorama/reference.js`; its example subject matter is not part of this style's required content.
